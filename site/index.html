    AutoPrompt help

    Everything the popup can do

    Pick prompts, set the pace, press Start. You can step in at any point, and AutoPrompt always waits for Copilot to finish answering before it sends the next one.

    5,770 built-in prompts in 11 categories

    Sample mode
    Choose a category, from General Knowledge and Coding to five sets of 1,000 questions, and tick the prompts you want.
    Custom mode
    Paste prompts one per line, or import a .txt, .csv or .json file. Save a set to load it again later.
    Delay
    Wait anywhere from 0.1 to 300 seconds between prompts.
    Start from
    Begin at any prompt number, like #150, to pick up where you left off.
    Pause, resume, stop
    Step in whenever you like. The batch picks up exactly where it paused.
    Page overlay
    A small badge on the Copilot tab shows which prompt is running and when the next one goes.
    Update notices
    The popup tells you when a new version is out, with a link to what's new.
