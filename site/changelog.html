Changelog

What's New

Every feature, improvement, and fix across all versions of AutoPrompt for Copilot.

v1.4.7 Latest November 2026

Stops the batch when Copilot's daily chat limit is reached.

Stops at the Daily Chat Limit

When Copilot replies "You've used your daily chat limit" or shows its "Upgrade to keep going" banner, AutoPrompt stops right away and sends nothing more, instead of using up the rest of your list on the same error. If the banner is already showing, no prompt is sent at all.

Pick Up Where It Stopped

The popup tells you which prompt hit the limit and fills in "Start from prompt #" with it, so you can continue the same list once the limit resets. The message stays until you press Start again.

v1.4.6 November 2026

A heads-up in the popup when a new version is out.

Update Notices

When a new version is released, the popup shows a small banner with a link to your browser's store and the release notes. It waits a day after the release so the store has time to publish it, and you can dismiss it.

v1.4.5 October 2026

A faster popup.

Faster Popup

The popup used to load all 5,800+ built-in prompts every time it opened. It now loads only the category you pick, and remembers the ones you've already opened, so switching back is instant.

Correct Prompts When Switching Quickly

Changing categories quickly could briefly show prompts from the category you picked before. The list now always matches the category you selected.

v1.4.0 October 2026

Works on Microsoft's new address for Microsoft 365 Copilot Chat.

copilot.cloud.microsoft Support

Microsoft moved Microsoft 365 Copilot Chat to copilot.cloud.microsoft, which made AutoPrompt report "Copilot tab not found". Batches now run there just like on m365.cloud.microsoft/chat.

v1.3.0 June 2026

Run batches in Copilot inside Microsoft Teams.

Teams Copilot Support

AutoPrompt now works with Copilot in the Teams web app, on teams.microsoft.com and outlook.office.com, bringing it to four Copilot platforms.

Reliable Typing in Teams

AutoPrompt waits for the Teams chat box to finish loading and enters each prompt in a way Teams recognizes, so prompts aren't lost or left unsent.

v1.2.0 June 2026

M365 Copilot, a Firefox version, thousands of new prompts, and faster batches.

M365 Copilot Support

Run batches on Microsoft 365 Copilot at m365.cloud.microsoft/chat, alongside Microsoft Copilot and GitHub Copilot.

Firefox Version

AutoPrompt is now available for Firefox, with the same features as the Chrome version.

5,700+ Built-in Prompts

New categories: Math Questions (250 and 500) and Questions Sets 1–5 with 1,000 prompts each.

Jump to Prompt

Start a batch from any prompt number, for example to pick up again at prompt #150.

Sub-Second Delays

Set the wait between prompts as low as 0.1 seconds. The default is now 1 second instead of 5.

Smooth With Large Batches

Prompt lists with 1,000 or more prompts now load and scroll smoothly.

v1.1.0 May 2026

Adds GitHub Copilot.

GitHub Copilot Support

Run batches on github.com/copilot as well as Microsoft Copilot. AutoPrompt adapts to each site's chat box automatically.

Waits for Long Answers

AutoPrompt detects when GitHub Copilot has finished answering, and allows up to 90 seconds for long responses before moving to the next prompt.

v1.0.0 May 2026

First release, for Microsoft Copilot.

Sample & Custom Modes

Pick built-in prompts by category, or paste your own, one per line.

Import From Files

Load prompts from a .txt, .csv, or .json file.

Playback Controls

Choose the delay between prompts, and pause, resume, or stop a batch at any time.

Live Progress

A progress bar and countdown in the popup, plus an overlay on the Copilot page showing which prompt is running.
